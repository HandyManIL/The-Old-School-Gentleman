The Old-School Gentleman — bilingual Hebrew/English site

Open index.html locally to preview. Hebrew is the default and the language switch is in the top navigation.

Before publishing:
1. Open index.html and set WHATSAPP_NUMBER to the business WhatsApp number in international digits-only format (for Israel, start with 972; omit the leading 0).
2. Verify all offered services, service area, pricing, and any claims before publishing.
3. Publish the b-old-school-gentleman folder to GitHub Pages or another static host.
4. Add the final domain to Search Console and submit a sitemap once a domain is available.

SEO included:
- Hebrew-first page title and meta description
- Natural Hebrew and English search phrases (including “בן זוג להשכרה”, “חבר להשכרה”, “ליווי לדייט”, and “boyfriend for hire”)
- Open Graph metadata, accessible image alt text, semantic headings, and responsive layout

The contact form does not send or store data on a server. It opens WhatsApp only after a real number is configured.
